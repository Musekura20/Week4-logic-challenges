## 3. How to Run the Files

Open the terminal inside the project folder and run one file at a time:

```bash
node round1.js
node round2.js
node round3.js
node boss.js
```

The results will appear in the terminal.

The longest bug I worked on was in the `compress()` function. I needed to make sure the last group of repeated characters was included in the result.

I fixed it by allowing the loop to reach the end of the string.
